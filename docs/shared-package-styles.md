# Shared styles

Public article components and styles live in `@byline/ui`, with Weekly Wildcat tokens in `@byline/theme-weekly-wildcat`. The public site and newsroom Live Preview use the same article presentation package.

The newsroom's Nova components live in `@byline/newsroom-ui`; Payload supplies the editor's form lifecycle. Editor-only styles belong in `@byline/editor`, and should reuse the same reader typography and visual components where possible.
