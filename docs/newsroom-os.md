# Working in Byline

- Start in Home for assignments, review requests, and upcoming commitments. Use Stories and Calendar for desk planning.
- Open a Story to plan assignments, report, write, review, and publish. See the [article editor](article-editor.md) and [reporting workflow](reporting.md).
- Use [Collections](collections-workspace.md) to group reporting. A Collection can optionally publish a public coverage or series page.
- Use [Media](media-workspace.md) to manage assets and production assignments. Public files are prepared separately from private originals.
- Use [Front Page](front-page.md) to place published stories in the homepage's existing slots and [Distribution](distribution.md) to track where they go.
- Check [content and deployment jobs](jobs.md) when a change has not reached the public site.

Payload's access checks apply to all staff operations. The public site contains only the published facts allowed by the snapshot contract.
